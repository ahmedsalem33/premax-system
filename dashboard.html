النشر على GitHub

ازاي تنشر في ٣ خطوات:
١. اضغط "حفظ التعديلات" بالأعلى
٢. الصق GitHub Token (مرة واحدة فقط — بيتخزن على جهازك في المتصفح، مش في الموقع)
٣. اضغط "نشر على GitHub الآن" — الموقع يتحدث تلقائيًا خلال دقيقة

إزاي تعمل Token: github.com/settings/tokens → Fine-grained token → الصلاحيات: Contents: Read & Write على مستودع premax-system بس.
لو مش عايزك التوكن على الجهاز: استخدم "تحميل data.js" واديه للريكويست بإيدك.
